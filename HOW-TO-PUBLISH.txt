DOSSIER — free website that stays online
========================================

This version does NOT use Render. It uses GitHub Pages.
Free. No sleep. Bookmark it forever.

Your link will look like:
https://YOURNAME.github.io/dossier/

STEP 1
Unzip this folder. You should see index.html, css, js, icon.svg.

STEP 2 — GitHub account
Go to https://github.com/signup and make a free account.

STEP 3 — New repository
1. Go to https://github.com/new
2. Repository name: dossier
3. Public
4. Do NOT add a README
5. Click Create repository

STEP 4 — Upload the site
1. On the new repo page click "uploading an existing file"
2. Drag in EVERYTHING from the unzipped folder:
   index.html, icon.svg, manifest.json, .nojekyll, css folder, js folder
3. Click Commit changes

STEP 5 — Turn on Pages
1. On the repo click Settings
2. Click Pages (left sidebar)
3. Under Build and deployment → Source: Deploy from a branch
4. Branch: main  (or master)   Folder: / (root)
5. Save
6. Wait 1 minute, then refresh that Pages settings page
7. GitHub shows a blue link:
   https://YOURNAME.github.io/dossier/

STEP 6 — Bookmark
Open that link. Press Ctrl+D (Mac: Cmd+D).
Put it on your Bookmarks bar.

If the page is blank, wait another minute and hard-refresh (Ctrl+Shift+R).
If css/js 404, you uploaded files inside an extra folder. They must sit
at the repo root, not inside another "public" or "dossier" folder.
